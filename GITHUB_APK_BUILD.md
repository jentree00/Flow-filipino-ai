# FLOW FILIPINO AI v5.0 — Cloud APK Build

This project is prepared for GitHub Actions so you can build the Android APK without installing Android Studio.

## Steps

1. Create a GitHub repository.
2. Upload the contents of this project to the repository.
3. Open **Actions**.
4. Select **Build FLOW FILIPINO AI APK**.
5. Click **Run workflow**.
6. When it finishes, open the completed workflow run.
7. Under **Artifacts**, download `FLOW-FILIPINO-AI-v5.0`.
8. Extract the downloaded artifact and install `FLOW-FILIPINO-AI-v5.0.apk` on your Android phone.

The workflow uses JDK 17, Android SDK 35, Android Gradle Plugin 8.7.3, and Gradle 8.10.2.

Note: this APK is the mobile UI/control/editor app. Wan 2.1 generation still needs the configured PC/GPU or cloud backend.
